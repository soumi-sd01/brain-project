# Conformal Calibration Under Missing MRI Modalities

Research project on conformal prediction for brain tumor MRI segmentation
under missing MRI modalities.

## Research Question

Does conformal prediction maintain reliable coverage when MRI modalities
are missing, and can modality-conditional calibration improve reliability?

## Planned Methodology

1. Prepare the BraTS MRI dataset.
2. Implement a 3D U-Net segmentation baseline.
3. Simulate missing MRI modalities.
4. Evaluate modality dropout.
5. Implement ordinary conformal calibration.
6. Implement modality-conditional calibration.
7. Compare coverage and prediction-set efficiency.

## Technology

Python, PyTorch, MONAI, NiBabel, NumPy, Matplotlib, Streamlit,
Google Colab, Git and GitHub.

## Project Status

Initial repository setup. No experimental results are claimed yet.

MRI datasets and model checkpoints will not be stored in this repository.
